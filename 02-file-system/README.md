# 📂 File System

The file system is essential for working with files and directories in Python.

Python provides several standard library modules that make it possible to create, read, modify, move, copy, and delete files and folders in a portable and reliable way.

## Learning Objectives

After completing this section, I should be able to:

- Navigate files and directories using `pathlib`.
- Work with file and directory paths.
- Understand relative and absolute paths.
- Use `os` for operating system interactions.
- Copy, move, and remove files with `shutil`.
- Create and manage temporary files with `tempfile`.
- Build practical file management utilities.
