# 📦 tempfile

The `tempfile` module provides safe temporary files and directories.

It is commonly used for testing, data processing, intermediate storage, and automation tasks where files should be automatically removed when no longer needed.

## Learning Objectives

After completing this section, I should be able to:

- Create temporary files.
- Create temporary directories.
- Use context managers with temporary resources.
- Understand automatic cleanup.
- Apply tempfile in real-world scenarios.
- Understand when to use `tempfile` instead of `pathlib`.
