# Introduction

This chapter introduces the `pathlib` module and the fundamentals of working with file system paths in Python.

## Learning Objectives

After completing this chapter, I should be able to:

- Import and use `Path`.
- Create `Path` objects.
- Understand relative and absolute paths.
- Use `Path.cwd()`.
- Use `Path.home()`.
- Build paths with the `/` operator.

## Topics Covered

- Path objects
- Relative paths
- Absolute paths
- Current working directory
- Home directory
- Path composition
