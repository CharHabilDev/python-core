# 📦 shutil

The `shutil` module provides high-level file and directory operations.

While `pathlib` focuses on path manipulation and `os` interacts with the operating system, `shutil` is designed to perform common file management tasks such as copying, moving, archiving, and removing directories.

## Learning Objectives

After completing this section, I should be able to:

- Copy files.
- Copy directories.
- Move and rename files.
- Remove directory trees safely.
- Create archives.
- Extract archives.
- Understand when to use `shutil`.
