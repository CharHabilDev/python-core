# OS

This module introduces Python's `os` module and its interaction with the operating system.

## Learning Objectives

After completing this section, I should be able to:

- Access operating system information.
- Read environment variables.
- Work with the current working directory.
- Navigate and inspect filesystem resources.
- Understand when to use `os` and when to use `pathlib`.
