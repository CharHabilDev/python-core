# strptime()

The `strptime()` method converts strings into datetime objects.

It allows applications to transform textual dates into objects that can be compared, calculated, and manipulated.

## Essential Syntax

```python
datetime.strptime(date_string, format)
```

Example:

```python
datetime.strptime("25/12/2026", "%d/%m/%Y")
```

## Key Concepts

- string → datetime
- date parsing
- user input
- CSV and API dates
- format validation
