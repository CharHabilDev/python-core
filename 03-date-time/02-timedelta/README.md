# ⏳ timedelta

The `timedelta` class represents a duration between two dates or times.

It allows Python applications to add, subtract, and manipulate periods of time.

## Learning Objectives

After completing this chapter, I should be able to:

- Create timedelta objects.
- Add durations to dates.
- Subtract dates.
- Calculate time differences.
- Work with days, hours, minutes, and seconds.
