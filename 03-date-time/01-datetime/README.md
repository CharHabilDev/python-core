# 📅 datetime

The `datetime` module provides classes for working with dates and times.

It allows Python applications to retrieve the current date and time, create custom dates, compare dates, and perform date-related operations.

## Learning Objectives

After completing this chapter, I should be able to:

- Import and use `datetime`.
- Get the current date and time.
- Access datetime components.
- Create datetime objects.
- Compare dates and times.
- Understand the role of `datetime`.
