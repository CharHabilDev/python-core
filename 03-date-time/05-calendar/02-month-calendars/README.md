# Month Calendars

## Goal

Learn how to display a monthly calendar using the `calendar` module.

## Main Concepts

### Display a Month

```python
calendar.month(year, month)
```

### Example

```python
print(calendar.month(2026, 1))
```

### Month Numbers

- 1 → January
- 6 → June
- 12 → December

## Remember

- `calendar.month()` displays a monthly calendar.
- `year` specifies the year.
- `month` specifies the month.
- Months are represented by numbers from 1 to 12.
