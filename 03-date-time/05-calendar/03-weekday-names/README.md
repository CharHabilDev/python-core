# Weekday Names

## Goal

Learn how to access weekday names with the `calendar` module.

## Main Concepts

### Weekday Names

```python
calendar.day_name
```

### Access a Day

```python
calendar.day_name[index]
```

### Examples

- `0` → Monday
- `2` → Wednesday
- `4` → Friday
- `6` → Sunday

## Remember

- `calendar.day_name` contains weekday names.
- Weekdays are represented by numbers from `0` to `6`.
- `0` is Monday.
- `6` is Sunday.
