# Introduction

## Goal

Understand the purpose of the `calendar` module and when to use it.

## Main Concepts

- `calendar` works with calendars.
- It can display months and years.
- It provides information about weeks and weekdays.
- It is useful for planning and scheduling applications.

## Comparison

- `calendar` → calendars, months, weeks, days
- `datetime` → dates and times
- `timedelta` → durations

## Remember

The `calendar` module helps organize time, while `datetime` represents specific moments.
