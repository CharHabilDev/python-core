# Event Manager

A simple CLI application to manage upcoming events.

## Features

- Add events
- View events
- Sort events by date
- Show upcoming events
- Delete events
- Validate user input

## Concepts Practiced

- `datetime`
- `timedelta`
- `strptime()`
- `strftime()`
- Lists
- Dictionaries
- Sorting
- Input validation
