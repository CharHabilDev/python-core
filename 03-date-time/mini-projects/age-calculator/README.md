# Age Calculator

A simple CLI application that calculates age-related information from a birth date.

## Features

- Calculate age in years
- Calculate days lived
- Display the next birthday
- Validate user input
- Reject future dates

## Concepts Practiced

- `datetime`
- `date`
- `strptime()`
- Date comparisons
- Date arithmetic
- Functions
- Input validation
