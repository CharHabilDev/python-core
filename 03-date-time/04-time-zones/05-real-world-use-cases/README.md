# Real-World Use Cases

## Goal

Understand how date and time tools work together in real applications.

## Common Workflow

User Input

↓

strptime()

↓

datetime

↓

timedelta

↓

new datetime

↓

strftime()

↓

Display

## Tools

- `datetime` → specific moment
- `timedelta` → duration
- `strptime()` → text to datetime
- `strftime()` → datetime to text
- `ZoneInfo()` → timezone
- `astimezone()` → timezone conversion

## Examples

- Hotel reservation
- Shared calendar
- Delivery tracking
- International meetings
- Social networks

## Remember

Real applications usually combine several date and time tools together.
