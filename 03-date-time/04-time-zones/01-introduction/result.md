| --------- | ------------- |
| UTC       |heure de référence mondiale               |

| UTC-5     |5 heures avant UTC               |

| Ville     | Exemple |

| Bruxelles |UTC+1    |
| Cotonou   |UTC+1    |
| Tokyo     |UTC+9    |         
| New York  |UTC-5    |

Choisis parmi :

```text
UTC+1
UTC+9
UTC-5
```

---

### Exercice 3

Réponds :

Si Bruxelles affiche :

```text
15:00
```

Tokyo affichera-t-il forcément :

```text
15:00
```

Pourquoi ?

#### Réponse : 
Parce que Tokyo utilise un fuseau horaire différent de Bruxelles.
Le même instant est affiché avec une heure locale différente.

### Exercice 8

Réponds avec tes propres mots :

1. Qu'est-ce qu'un fuseau horaire ?
    - C'est une région qui utilise une même heure
2. Pourquoi UTC est-il important ?
    - C'est la référence horaire mondiale
3. Pourquoi deux pays peuvent-ils afficher des heures différentes au même moment ?
    - Parcequ'il ne sont pas sur le même fuseau horaire
4. Cite deux applications qui doivent gérer les fuseaux horaires.
    - réservation de vols
    - agenda partagé
    - WhatsApp
    - Google Calendar
    - Zoom
    - réseaux sociaux
5. Quel problème pourrait arriver si une application ignore les fuseaux horaires ?
    - réunions à la mauvaise heure
    - messages affichés dans un ordre incorrect
    - réservations décalées
    - erreurs dans les échéances
    - vols affichés avec une mauvaise heure
