# Time Zones

The `datetime` module can work with time zones.

Time zones allow applications to represent the same instant differently depending on a user's location.

Without proper time zone handling, applications may display incorrect dates and times, especially when users are located in different countries.

## Learning Objectives

After completing this chapter, I should be able to:

- Understand what a time zone is.
- Understand the difference between naive and aware datetimes.
- Understand UTC.
- Use the `zoneinfo` module.
- Convert dates and times between time zones.
- Understand real-world time zone scenarios.
