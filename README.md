# 🐍 Python Core

A structured repository for mastering Python core concepts and the standard library.

This repository serves as my personal Python reference, covering core concepts, the standard library, best practices, exercises, and mini-projects.

## Goals

- Deepen my understanding of Python.
- Build a long-term reference.
- Practice with focused examples.
- Apply concepts through mini-projects.
- Prepare for Object-Oriented Programming and Python web frameworks.

---

## Learning Philosophy

The purpose of this repository is not to collect code snippets, but to understand Python concepts through explanations, practical examples, exercises, and mini-projects. Each topic is documented progressively as it is learned and practiced.
