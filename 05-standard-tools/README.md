# Phase 5 - Standard Tools

This phase introduces Python's standard utility modules used to write cleaner, faster, and more maintainable code.

## Objectives

By the end of this phase, you should be able to:

- Work efficiently with iterables.
- Simplify common programming tasks.
- Optimize code when appropriate.
- Build reusable solutions using the standard library.

---

## Chapters

### 01 - Itertools

Iterator utilities and combinatorics tools.

### 02 - Functools

Functional programming and optimization utilities.

### 03 - Operator

Callable versions of common operators.

### 04 - Collections Utilities

Additional collection-related tools.

### 05 - Copy

Object copying and cloning.

### 06 - Enum

Readable and maintainable constants.
