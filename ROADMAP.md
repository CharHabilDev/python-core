# 🐍 Python Core Roadmap

## Vision

The goal of this repository is to build a solid understanding of Python beyond the fundamentals by exploring the language's core features, the standard library, development best practices, testing, and performance.

This repository focuses on writing clean, maintainable, and reusable Python code while progressively preparing for object-oriented programming, web development, and larger software projects.

Each phase includes:

- explanations;
- practical examples;
- exercises;
- mini-projects.
