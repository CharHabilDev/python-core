# Collections

Python provides specialized collection types that extend the capabilities of built-in data structures.

These tools help solve common problems such as counting elements, handling missing keys, creating efficient queues, and working with lightweight data records.

## Learning Objectives

After completing this phase, I should be able to:

- Count data efficiently with `Counter`.
- Handle missing dictionary keys with `defaultdict`.
- Use fast queues with `deque`.
- Create lightweight records with `namedtuple`.
- Choose the appropriate collection for a specific problem.
