# defaultdict Practice

These exercises are designed to reinforce the concepts learned in the defaultdict module.

## Exercises

| # | Exercise | Concepts |
|---|----------|----------|
| 1 | Expense Grouping | defaultdict(list) |
| 2 | Students by Class | Grouping data |
| 3 | Events by Month | Automatic initialization |
| 4 | Rabbit Breeds Registry | defaultdict(set) |

## Objectives

After completing these exercises, I should be able to:

- Use default factories.
- Group data efficiently.
- Avoid manual key initialization.
- Choose the appropriate factory.
- Apply defaultdict to real-world problems.
