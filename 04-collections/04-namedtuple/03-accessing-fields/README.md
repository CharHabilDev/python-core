# Accessing Fields

## Summary

### Access by Name

```python
person.name
person.age
person.country
```

### Access by Index

```python
person[0]
person[1]
person[2]
```

### Advantages

* Better readability
* Self-descriptive code
* Easier maintenance

### Comparison

```text
person[1]

↓

What is it?
```

```text
person.age

↓

Immediately clear
```

### Key Idea

```text
namedtuple

↓

field names

↓

readable access
```
