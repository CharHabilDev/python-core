# namedtuple

`namedtuple` creates lightweight tuple-like objects whose fields can be accessed by name.

It combines the simplicity of tuples with improved readability.

## Learning Objectives

After completing this chapter, I should be able to:

- Understand what a `namedtuple` is.
- Create custom namedtuple types.
- Access values using field names.
- Compare `namedtuple` with regular tuples.
- Use `namedtuple` to represent structured data.
