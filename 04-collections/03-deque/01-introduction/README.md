# Introduction

## Summary

### deque

A deque is a double-ended queue.

It allows efficient insertion and removal of elements from both ends.

### Benefits

- Fast operations on both ends
- More efficient than a list for front operations
- Can be used as a queue or a stack

### Common Operations

- append()
- appendleft()
- pop()
- popleft()

### Common Use Cases

- Task queues
- Browser history
- Undo/Redo systems
- Message processing
- Log buffers
