# Introduction

## Summary

### Counter

`Counter` is a specialized dictionary from the `collections` module.

It is designed to count occurrences of elements automatically.

### Import

```python
from collections import Counter
```

### Purpose

Counter is useful when counting:

- Words
- Characters
- Votes
- Survey results
- Log entries

### Advantages

- Less code
- Easier to read
- Automatic counting
- Part of the standard library
