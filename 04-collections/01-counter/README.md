# Counter

`Counter` is a specialized dictionary used for counting hashable objects.

It automatically stores the number of occurrences of each element.

## Learning Objectives

After completing this chapter, I should be able to:

- Understand what a Counter is.
- Count elements in an iterable.
- Access frequencies.
- Retrieve the most common elements.
- Apply Counter to real-world scenarios.
