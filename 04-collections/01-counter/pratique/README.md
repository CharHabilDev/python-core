# Counter Practice

These exercises are designed to reinforce the concepts learned in the Counter module.

The goal is to apply Counter in realistic situations before moving on to larger projects.

## Exercises

| # | Exercise | Concepts |
|---|----------|----------|
| 1 | Word Frequency | Counter, most_common |
| 2 | Vote Counter | Counting, ranking |
| 3 | Log Analysis | Frequencies, access counts |
| 4 | Rabbit Statistics | Counting categories |

## Objectives

After completing these exercises, I should be able to:

- Create a Counter from different iterables.
- Access element frequencies.
- Use `most_common()`.
- Identify situations where Counter is useful.
- Apply Counter to real-world datasets.
