# Exercices

## Exercice 1

Crée une fonction :

```python
compte_a_rebours(n)
```

qui affiche :

```text
5
4
3
2
1
Décollage !
```

pour :

```python
compte_a_rebours(5)
```

---

## Exercice 2

Crée une fonction récursive :

```python
somme(n)
```

qui retourne :

```text
1 + 2 + 3 + ... + n
```

Exemple :

```python
print(somme(5))
```

Résultat :

```text
15
```

---

## Exercice 3

Crée une fonction récursive :

```python
puissance(base, exposant)
```

Exemple :

```python
puissance(2, 3)
```

Résultat :

```text
8
```

Sans utiliser :

```python
**
pow()
```

## Exercice 4

Crée une fonction récursive :

```python
compter_lettres(mot)
```

qui retourne le nombre de caractères d'une chaîne.

Exemple :

```python
compter_lettres("python")
```

Résultat :

```text
6
```

Sans utiliser :

```python
len()
```

## Exercice 5

Réponds avec tes propres mots :

1. Qu'est-ce qu'une fonction récursive ?
2. Pourquoi faut-il un cas d'arrêt ?
3. Que se passe-t-il sans cas d'arrêt ?
4. Quelle différence vois-tu entre une boucle et une récursion ?
5. Dans quels types de problèmes la récursion est-elle particulièrement utile ?

Petit avertissement : la récursion est l'un des sujets où il faut parfois dessiner l'exécution sur papier. Beaucoup de développeurs comprennent la syntaxe immédiatement mais mettent quelques jours à vraiment visualiser comment les appels s'empilent puis se dépilent. C'est normal, et c'est précisément ce qui rend ce chapitre formateur.
