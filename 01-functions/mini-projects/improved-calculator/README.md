# Improved Calculator

## Overview

A command-line calculator built to practice Python functions, user input handling, validation, and exception management.

This project was created during the **Functions** phase of the Python Core roadmap.

---

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Error handling
- Interactive menu

---

## Concepts Practiced

- Functions
- Parameters
- Return values
- Conditional statements
- Loops
- Exception handling
- User input validation

## Usage

Run the program:

```bash

```
