# Password Generator

## Overview

A command-line password generator built to practice Python functions, optional parameters, input validation, and code organization.

The application allows users to generate random passwords with customizable options such as uppercase letters, digits, and symbols.

This project was created during the **Functions** phase of the Python Core roadmap.

---

## Features

- Generate random passwords
- Custom password length
- Optional uppercase letters
- Optional digits
- Optional symbols
- Input validation
- Error handling

## Usage

Run the application:

```bash
python main.py
```

Example:

```text
Générateur de mots de passe

Longueur : 16
Majuscules ? (o/n) : o
Chiffres ? (o/n) : o
Symboles ? (o/n) : o

Mot de passe généré :
A#7mP!2xQ8@kL4nZ
```
