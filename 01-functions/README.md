# 📚 Functions

Functions are one of the most important building blocks in Python.

They help organize code, avoid repetition, improve readability, and make programs easier to maintain.

## Learning Objectives

After completing this section, I should be able to:

- Create reusable functions.
- Use positional and keyword arguments.
- Define default values.
- Work with `*args` and `**kwargs`.
- Understand variable scope.
- Use lambda functions appropriately.
- Understand recursion.
- Create generators using `yield`.
- Understand how decorators work.
