# Exercices

## Exercice 1

Crée une fonction :

```python
addition(*args)
```

qui additionne tous les nombres reçus.

Teste :

```python
addition(1, 2)
addition(1, 2, 3)
addition(1, 2, 3, 4, 5)
```

---

## Exercice 2

Crée une fonction :

```python
afficher_notes(*args)
```

qui affiche chaque note sur une ligne.

Exemple :

```python
afficher_notes(12, 15, 18)
```

## Exercice 3

Crée une fonction :

```python
afficher_profil(**kwargs)
```

qui affiche :

```text
nom: Ali
age: 20
ville: Cotonou
```

pour n'importe quelles données reçues.

---

## Exercice 4

Crée une fonction :

```python
creer_utilisateur(username, **kwargs)
```

qui affiche :

```text
Username: charles
email: ...
age: ...
role: ...
```

Le `username` doit être obligatoire, les autres informations optionnelles.
