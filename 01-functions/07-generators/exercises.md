# Exercices

## Exercice 1

Crée un générateur :

```python
nombres()
```

qui produit :

```text
1
2
3
4
5
```

Utilise :

```python
for nombre in nombres():
    print(nombre)
```

## Exercice 2

Crée un générateur :

```python
pairs(limite)
```

qui produit tous les nombres pairs jusqu'à `limite`.
